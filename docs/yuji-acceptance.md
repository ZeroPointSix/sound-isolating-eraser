## 真实客户端方法

### a26 稳定性修正（2026-10-12）

- 在 `0b628a8` 生产代码上，用真实客户端在每次贪欲咬击动作开始时暂停渲染线程 1600 ms，复现 `tanyu.bite` 未发出：服务器已吃腐肉至 3 层并造成 5 次伤害，客户端动作序号连续跳转，但没有咬击声音请求。首轮配置的 5 FPS 被 Minecraft 拒绝并退回默认值，因此该轮只作为卡顿复现，不称作 5 FPS 验证。
- 咬击音效改为服务器在原第 12 action tick 发出，伤害/距离判断不变；挥空仍有动作音。客户端取消同一动作的重复声音，保留粒子。新增命中/挥空两个正式 GameTests，逐 tick 验证声音恰好一次及实际伤害时点。
- 愚痴沿用 `0b628a8` 的有界渲染就绪修正，保持 `frames > 10`、骨骼运动、前景像素与构图条件。新增 10 FPS 加每帧 700 ms 延迟的真实渲染回归，不伪造帧数、不跳过截图断言。
- 短音效通过 Forge 在 `Channel.play()` 后触发的实际播放回调记录 `channelPlaying=true`，避免渲染线程恢复时 0.6 秒的声音已经结束而漏记；仍保存声音请求、SoundManager 活跃检查、实际混音。回调不负责触发或伪造声音。
- `5c83186` 的两次新世界真实客户端压力回归均通过：10 FPS 上限、每帧额外 700 ms、咬击序号变化暂停 1600 ms；每轮愚痴/贪欲各 11 个真实帧，贪欲 3 层、5 次伤害、5 次实际咬击播放。原始日志/截图/混音及首次 CI 新增测试夹具失败记录均见 [a26 证据](validation/yuji/a26-stability/README.md#recorded-local-results)。修正无遮挡测试站位后，本地新世界编译及 46/46 雨寂 GameTests 通过；首次 CI 不能当作绿灯，后续 HEAD 的全量 CI 仍单独核对。
- CI 在两个独立新世界重复全量 GameTest，并在全量逐怪、双客户端边界、声音/视角隔离、关门/攀墙/Panda 场景之外增加两轮定向压力回归。定向模式明确标注 `profiles=yuchi,tanyu`，不能当作全量验收。
- 结果以当前 HEAD 的 CI、[a26 证据索引](validation/yuji/a26-stability/README.md) 和 PR 最新评论为准。人工听音、真人多人玩法感受及任意地形穷举仍未签收，本轮不是独立 Review 或最终需求验收。

`tools/yuji/e2e.py` 启动真实 Forge 专用服务器和完整 Minecraft 客户端，以 `YujiTester` 通过回环 TCP 连接；双客户端专项另启动 `YujiWitness`。客户端使用 Xvfb/软件 OpenGL，默认使用 OpenAL null 输出设备；指定 `YUJI_QA_RECORD_AUDIO=1` 时改用各客户端独立的 wave 输出设备并转码为 Ogg。不是截图合成、Mock 客户端或假玩家。操作由独立 QA 模组自动执行，不是人工手动游玩。

每个生物先固定相机采集可复核渲染截图，再启用真实 AI 与生存玩家互动，不手工指定 AI 目标、不直接调用技能来代替自然触发。探针记录玩家 UUID、实际位移、伤害事件、状态和物理碰撞。音频阶段经真实伤害/死亡流程触发声音，记录声音事件、解码后的资源、播放活跃状态和音量。

默认 OpenAL null 不产生可听录音；录音模式保存实际混音、转码记录与非静音检查。两种模式都不能证明经过人的听觉音质验收。GameTest 中的边界单元用例与真实客户端验收分层报告，不把 GameTest 的测试玩家当作真实玩家证据。

```bash
set -o pipefail
mkdir -p build
python3 tools/yuji/validate_assets.py
# Dedicated QA world only; remove stale GameTest state before regression.
rm -rf run/world
bash ./gradlew build runGameTestServer --no-daemon --stacktrace 2>&1 | tee build/yuji-gametest.log
python3 tools/yuji/verify_gametest_log.py build/yuji-gametest.log
bash ./gradlew -PyujiE2E writeYujiTestClasspath --no-daemon
python3 tools/yuji/e2e.py
```
