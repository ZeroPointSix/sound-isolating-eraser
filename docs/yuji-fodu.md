基于用户提供的 `yuji_fodu_monsters.zip` v0.2，接入现有 Forge 1.20.1 / GeckoLib 4 模组，不新增第二个发布模组。实体、材质、音效保留 `qihai` 命名空间。

本次不添加自然刷新、召唤仪式、黑雨或世界生成规则，不改变现有城市生成模块。

## 配置与存档

世界的 `serverconfig/qihai-yuji-server.toml` 提供众叛对宠物/村民的影响开关、敌怪增益、迷魂拉力/转向、诅咒伤害上限和贪欲层数上限。

被偷及拾取的物品保留完整堆叠和 NBT，随生物存档保存，并阻止携物者自然消失。死亡时独立归还玩家物品，即使 `doMobLoot=false` 也不会丢失，不会重复归还。

三种自定义状态分别记录来源；来源失效时只移除其影响。众叛解除时恢复宠物原有坐下指令、目标和临时属性。妄语使用原版虚弱，牛奶可以解除；三个自定义状态不可用牛奶清除。

## 资源与验证

原始设定及参考图保存在 `art/yuji_fodu/`，游戏实际资源位于 `src/main/resources/assets/qihai/`。原 ZIP SHA-256 为 `c034d4c9aa7685255fb182fa3ff07b12af5c52b1c813438ebd6843ee73a8bc1f`；导入器拒绝来源不符或覆盖已修改资源。

```bash
python3 tools/yuji/validate_assets.py
bash ./gradlew build runGameTestServer --no-daemon
```

独立复验本模块可加 `-PyujiOnly`。将运行日志交给 `python3 tools/yuji/verify_gametest_log.py <log>`，可拒绝未发现用例、部分完成或失败的运行。

真实客户端烟测复用仓库独立 QA 模组方式，不进入玩家 Jar：

```bash
bash ./gradlew -PyujiE2E writeYujiTestClasspath --no-daemon
python3 tools/yuji/e2e.py
```

需本机 Xvfb 和软件 OpenGL；仅监听回环地址的测试服按仓库既有 E2E 方式运行。证据写入 `build/yuji-e2e-*/`，包含十一种生物及骨刺的实际游戏截图、动画骨骼变化、真实玩家 AI/碰撞、逐怪声音播放、声音衰减和循环停止记录。OpenAL 使用 null 输出设备，检查真实声音引擎的解析与播放，不声称已经人工听音。具体覆盖和证据见 [需求与验收对照表](yuji-acceptance.md)。这是单客户端验收，仍不能替代下述双玩家专项验收。

资源校验覆盖十二套模型/动画、十一枚蛋、三种状态图标、十九套粒子、全部声音引用、特效骨骼和动画时序。`YujiGameTests` 覆盖物品保存归还、成长边界、多来源状态解除、牛奶、众叛属性/宠物恢复、投射物和伤害抗性。

### 客户端验收清单

- 在隔离世界逐一生成十一种生物，检查材质、透明区域、发光和出生蛋。
- 检查行走、攻击和死亡动画，以及骨骼绑定粒子的空间位置。
- 持物偷盗者重新登录后仍携带原堆叠，死亡只归还一次。
- 两名玩家验证假声只传给目标，迷魂转向只影响受控玩家。
- 检查笛声区域内其他敌怪声音衰减，以及十佛头血条、音乐和离开范围后的停止。

自动化服务端测试不等同于上述真实客户端视觉、音频及多人验收；实际通过情况以 PR 验证记录为准。
